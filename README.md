Program 1: Count Words

Description
- 
A simple Python program that counts the number of words in a sentence entered by the user. It also displays a special message if the user enters an empty sentence

Features
-
- Accepts a sentence from the user
- Counts a total number of words
- Displays a special message if the input is empty or contains only spaces

How to Run
-
1. Make sure Python 3 is installed on your computer.
2. Save the program as count_words.py
3. Open a terminal in the project folder.
4. Run the following command:
    python count_words.py
